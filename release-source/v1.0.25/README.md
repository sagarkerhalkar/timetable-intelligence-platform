# v1.0.25 sanitized release source

This directory contains the frontend source changed for the v1.0.25 Paged UX + Larger QR Library release candidate.

Included:
- large paged My QR Codes library;
- source/QR link copy controls;
- QR preview modal;
- multi-select deletion;
- Templates/Bulk/Analytics pagination;
- shared pagination utility, component and tests.

This public snapshot intentionally excludes databases, private runtime data, secrets and customer assets.

Acceptance rule: this source is not stable until the Windows installer passes the complete backend/web/strict-TypeScript/Next.js/runtime regression gate without rollback.
