# v1.0.24 release-source snapshot

This directory documents the code changes for the v1.0.24 release candidate while the public repository remains intentionally small and safe.

Included here are the actual new frontend pages and permanent backend regression test. The production ZIP contains the complete cumulative source payload and Windows rollback installer.

The public source snapshot intentionally contains source code only. It does not contain databases, credentials, private Sheet contents, recipient data, runtime logs, cookies/tokens or uploaded branding assets.
