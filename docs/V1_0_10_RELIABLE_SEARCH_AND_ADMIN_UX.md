# v1.0.10 — Reliable hyperlink search and clear admin workflow

## Search root cause

`YT Science 2026-27` uses `YT Link` in Class 11 but `Remarks` in Class 12 for cells containing YouTube hyperlinks. v1.0.10 scans actual hyperlinks and URLs in every physical column, so custom headings cannot hide valid learning content.

Validated live export:

- Class 11 structured links: 81
- Class 12 structured links: 77
- Structured total: 158
- Full merged sync: 172

## Administration improvements

- Exact per-Sheet and per-tab search coverage.
- Prominent connected-Sheet manager and Remove Sheet action.
- Professional Test Analysis dashboard with operational, subject, class and course analytics.
- Person/group guidance for Personal WhatsApp, Telegram and Google Chat Spaces.
- Normal-user change stories hide raw row/cell coordinates and show exact Before/After values.

The Windows installer protects port 3457 and validates the live Class 12 index before reporting success.
